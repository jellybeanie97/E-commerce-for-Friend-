# Website Shop

Building my friend's E-commerce website, Lumea, a small business selling beauty products.

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Prisma + Supabase (PostgreSQL)
- NextAuth.js v5

## Features

- Customer storefront with product browsing
- Customer authentication (signup/login)
- Admin dashboard for product inventory/management
- Role-based access control
